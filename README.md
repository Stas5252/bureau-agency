# BUREAU [БЮРО] — сайт event-агентства

Контент (тексты, фотографии, объекты, палитра) взят из брендборда `bureau.png`.
Дизайн и анимация построены по референсам awwwards / savee — крупная кинетическая
типографика, полноэкранные медиа, blend-режимы, скролл-хореография.

## Запуск

```bash
npm --prefix app run dev
```

Сборка: `npm --prefix app run build`, проверка кода: `npm --prefix app run lint`.

## Контент из брендборда

Перенесено всё, что есть в `bureau.png`: хедлайн и три мета-блока первого экрана,
надпись на вращающемся бейдже, «Наши награды и достижения», обе коллекции Wedding
Awards (13 + 2 позиции), регалии и составы жюри, «Ежегодный победитель премии
Wedding Awards», 7 услуг с описаниями, 11 этапов «Полного цикла», консультации
(1,5 часа, аудитория из 10 пунктов, две колонки пользы по 6 пунктов), 4 отзыва,
оба финальных заявления и фотосетка.

## Анимационный слой

Всё на GSAP 3.15 (в пакете доступны все плагины):

- **ScrollSmoother** — инерционный скролл + `data-speed` параллакс.
- **SplitText** — маскированный ввод строк и букв.
- **ScrollTrigger** — пиннинг манифеста и горизонтального «Полного цикла»,
  скраб-переходы, смена темы страницы посекционно.
- **Flip** — раскрытие фото портфолио в лайтбокс из позиции миниатюры.
- **DrawSVG** — рисование стрелок и волнистой линии.
- **ScrambleText** — перебор букв на пунктах меню.

Общие хелперы — в `src/lib/anim.js` (`revealLines`, `magnetic`, `velocitySkew`,
фирменные easing-кривые `bureau*`).

### Порядок секций

1. `Preloader` — счётчик реальной загрузки картинок, шторки-колонны.
2. `Hero` — блэклеттер-логотип, лента фотографий, вращающийся бейдж, растворение на скролле.
3. `Ticker` — бегущая строка, реагирующая на скорость скролла.
4. `Manifesto` — пиннинг, 4 полноэкранных кадра, difference-типографика.
5. `Services` — «Спектр услуг», превью за курсором, ключ с параллаксом.
6. `Process` — «Полный цикл», горизонтальный скролл 11 этапов.
7. `Awards` — счётчики и списки премий.
8. `Consultation` / `Benefits` — 1,5 часа, шкаф, рисованные стрелки.
9. `Reviews` — стопка карточек-отзывов.
10. `Gallery` — 4 колонки с разной скоростью + лайтбокс.
11. `Footer` — гигантский логотип, контакты, время в Самаре.

## Мобильная версия

Телефон получает отдельный сценарий, а не сжатый десктоп:

- **ScrollSmoother не создаётся на тач-устройствах.** Там он означает `position: fixed`
  обёртку с transform, который считается из JS и всегда отстаёт от компоновщика при
  инерционном скролле — на телефоне это читается как дёрганье. Плата — нет
  `data-speed` параллакса на мобильном, и это правильный размен.
- Пиннинг: остаётся только манифест и уже не 4.4, а 2.5 экрана. Герой на тач-устройствах
  не пиннится.
- «Полный цикл» из скраб-трека превращается в нативную свайп-карусель со snap
  и подсказкой «листайте →»; счётчик и прогресс считаются от `scrollLeft`.
- Всего прокрутки: 16.5 экрана против 22.7 на десктопе.
- Hover-состояния продублированы для `(hover: none)`: описания услуг и подписи
  к фото видны сразу, тап-зоны в футере и меню увеличены.
- Меню и лайтбокс блокируют страницу через `body.overflow`, когда смузера нет.

## Типографика в масках

Любая маска (`.mask`, `.split-line-mask`, `.mark-char-mask`, `.ftr-char-mask`)
получает в `index.css` паддинг `0.18em 0.07em 0.17em` с равным отрицательным
margin. Без него клип по line-box срезает бревис у «Й», точки у «Ё», хвосты
у «Ц/Д/у/р» и свеши блэклеттера. Из-за этого паддинга стартовые смещения
reveal-анимаций держатся на уровне **135–145 %** — меньшие значения оставят
край буквы видимым до начала анимации.

## Доступность и производительность

- При системной настройке «уменьшить движение» сайт отдаёт статичную версию:
  без прелоадера, пиннинга и смус-скролла. Проверить принудительно:
  `?motion=1` — включить анимации, `?motion=0` — выключить.
- Курсор, прелоадер, шапка и лайтбокс вынесены за пределы `#smooth-content`
  (в трансформированном контейнере `position: fixed` не работает).
- `window.gsap` / `ScrollTrigger` / `ScrollSmoother` доступны в консоли для отладки.
